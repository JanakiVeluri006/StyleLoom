# StyleLoom AI — Reimagined Myntra Fashion Suite

StyleLoom is an intelligent fashion composer and AI recommendation platform built for personalized outfit discovery, attribute composition, coordinated matching, and A-Z outfit completion.

## Features
- **Myntra Dataset Catalog**: Visually aligned dataset covering Men, Women, Kids, Beauty, GenZ, and Home decor.
- **3D Preference Bucket**: Compose taste profiles with real-time flying attribute animations (`My Bucket`).
- **Recommendation Deck**: Gesture and button-controlled swiping deck matching your exact bucket preferences.
- **A-Z Outfit Completer**: Automated matching for footwear, bags, clutches, and jewelry.
- **Coordinated Matching Suite**: Matching outfits for Couple Fits, Sisters, Friends, and Family.
- **Deduplicated Picks**: 100% unique card rendering on your swiped items page.

## Running Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to launch the application.
